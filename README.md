# Song Lyrics Terminal Project

A simple and elegant Python script that displays song lyrics in the terminal with a smooth typing animation effect and green console coloring.

## How to Run
1. Ensure you have **Python** installed on your system.
2. Open your terminal and navigate to the project folder.
3. Run the script using the following command:
   ```bash
   python lyrics.py

Features:
Typing Animation: Text appears character-by-character for a cinematic effect.

Color Styling: Uses ANSI escape codes for a sleek green terminal aesthetic.

Customizable: You can easily modify the lyrics list in the script to display your favorite songs.

Requirements:
This project uses standard Python libraries (sys, time, os), so no external installations are required.
